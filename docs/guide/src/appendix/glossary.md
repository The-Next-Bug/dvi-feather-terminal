# Glossary

| Term | Meaning |
|---|---|
| ADM-3A | Lear Siegler's 1976 terminal; one of the [terminal types](../terminal/terminal-types.md) |
| AY-3-8910 | General Instrument's sound chip: three tones, noise, an envelope; emulated for the Z80 |
| BDOS, BIOS, CCP | CP/M's disk operating system, its hardware layer, and its command processor |
| BOOTSEL | the RP2350's button for flashing over USB |
| CSI | Control Sequence Introducer: `ESC [` |
| DECCKM, DECKPAM | the VT100's cursor key and keypad application modes |
| DPB | CP/M's disk parameter block: a disk's geometry |
| DVI | Digital Visual Interface: the video signal HDMI carries |
| FatFs | ChaN's FAT file system library, for the SD card and sticks |
| HSTX | the RP2350's high-speed serial transmit peripheral, with a TMDS encoder |
| LNM | New line mode: Return sends CR LF, LF also returns the cursor |
| PSG | a file of AY register writes per frame |
| PSRAM | pseudo-static RAM on the flash's QSPI bus, on some boards |
| RIS | Reset to Initial State: `ESC c` |
| SGR | Select Graphic Rendition: `CSI ... m`, attributes and colors |
| SET-UP | the settings panel (F12) |
| TMDS | the encoding DVI and HDMI use on their data lanes |
| TPA | CP/M's transient program area: the memory programs get |
| UF2 | the firmware file format for flashing |
| XIP | execute in place: running code from flash through a cache |
