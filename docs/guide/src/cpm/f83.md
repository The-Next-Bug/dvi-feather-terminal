# F83 Forth

The `F83` disk (built in, 8 MB) holds Henry Laxen and Michael Perry's F83,
FORTH-83 2.0 for CP/M-80 (public domain): `F83.COM` ready to run, the
system's source as block files (`KERNEL80.BLK`, `META80.BLK`,
`CPU8080.BLK`, `EXTEND80.BLK`, `UTILITY.BLK`), examples (`CLOCK.BLK`,
`HUFFMAN.BLK`, `BASIC.BLK`, a BASIC compiler) and its manual, `README.80`.

## Running it

Mount `F83` on B: under CP/M 2.2 or 3 and run it, with a block file to open
if you like:

```
A>B:
B>F83 CLOCK.BLK
8080 Forth 83 Model
Version 2.1.0 Modified 01Jun84
2 3 + . 5  ok
1 LIST
BYE
```

`README.80` is a WordStar file (high bits set), so `TYPE` shows it garbled;
`-READ.ME` and `F83-FIXS.TXT` are plain text.

## VIEW

`VIEW name` (and the editor's `FIX`) lists the source screen of a word. The
original F83 opens the source files on the current drive, so under CP/M 3,
where `F83` typed at `A>` is found on B: through the search path, it fails
with `Open error`. The disk's `F83.COM` is patched (`VIEWDRV.BLK`) to look
on the drive it was loaded from, which CP/M 3 records. CP/M 2.2 does not
record it, so there start F83 from its own drive (`B:`, then `F83`). After
rebuilding F83 from its source (`README.80`), `F83 VIEWDRV.BLK` and then
`1 LOAD` patch and save the new `F83.COM` the same way.

The patch adds three words:

| Word | Stack | What it does |
|---|---|---|
| `LOAD-DRIVE` | `( -- n )` | the drive F83 was loaded from (1 = A:), read from 0050h under CP/M 3; 0 under CP/M 2.2 |
| `VIEW-DRIVE` | `( -- )` | put that drive into each `VIEW-FILES` file's drive byte |
| `HELLO-VIEW` | `( -- )` | the start-up word: `VIEW-DRIVE`, then F83's `HELLO` |

## Stack diagrams

Each word below is shown with its stack diagram, `( before -- after )`:
the items it takes from the data stack on the left of `--`, those it
leaves on the right, the top of the stack rightmost in both. So
`AY! ( b reg -- )` takes a register number from the top and a byte below
it, and leaves nothing: `7 0 AY!` writes 7 to register 0. F83's own
sources, and AY.BLK, write the same diagrams as `(S ... )` comments.

| Symbol | Meaning |
|---|---|
| `n` | a number, 16 bits, signed |
| `u`, `period`, `ms`, `hz` | a number, 16 bits, unsigned |
| `b` | a byte, 0-255 |
| `f` | a flag: 0 false, -1 true |
| `addr` | an address |
| `reg` | an AY register, 0-16 |
| `ch` | an AY channel: 0 A, 1 B, 2 C |
| `port` | a Z80 I/O port, 0-255 |

Numbers are decimal unless `HEX` is in effect, as F83 reads them.

## Ports from Forth

F83 reads and writes the Z80's [I/O ports](../reference/ports.md) with two
words of its own:

| Word | Stack | What it does |
|---|---|---|
| `PC@` | `( port -- b )` | `IN`: read a byte from the port |
| `PC!` | `( b port -- )` | `OUT`: write a byte to the port |

For instance, the clock's seconds (in BCD; ports 41h and 42h are 65 and
66) and a check for a waiting key on the console's status port:

```
: SECONDS   ( -- b )   0 65 PC!  66 PC@  ;
: KEY-WAITING   ( -- f )   0 PC@  1 AND  0=  ;
SECONDS .
```

## The sound chip: AY.BLK

`AY.BLK` has words for the [AY-3-8910](../terminal/sound.md): run
`F83 AY.BLK`, then `1 LOAD`, then for example `SCALE`, `CHORDS`, `SIREN`,
`DRUM`, `PAN` (A, B and C in each stereo layout) or `TUNE`. The chip's
registers are described on the
[I/O ports](../reference/ports.md#the-ay-3-8910-d8h-d0h) page.

### The chip (screen 2)

| Word | Stack | What it does |
|---|---|---|
| `AY-SELECT` | `( -- port )` | the register select port, 216 (D8h) |
| `AY-DATA` | `( -- port )` | the data port, 208 (D0h) |
| `AY!` | `( b reg -- )` | write b to a register |
| `AY@` | `( reg -- b )` | read a register |
| `AY?` | `( -- f )` | true if the chip is there (writes 255 to register 1 and reads back 15) |
| `TONE` | `( period ch -- )` | a channel's tone period, 1-4095 (115200 / f for f Hz) |
| `VOLUME` | `( n ch -- )` | a channel's level: 0-15, or 16 to follow the envelope |
| `NOISE` | `( period -- )` | the noise period, 0-31 |
| `VOICES` | `( tones noises -- )` | the mixer: two masks (1 A, 2 B, 4 C) of the channels with tone and with noise; `7 0 VOICES` is all tones, no noise |
| `ENVELOPE` | `( period shape -- )` | the envelope's period (0-65535) and shape (0-15), and start it |
| `QUIET` | `( -- )` | registers 0-13 to 0 and the mixer off: silence (the stereo layout is left alone) |
| `STEREO` | `( n -- )` | the stereo layout (register 16): 0 the setting's, 1 mono, 2 ABC, 3 ACB |

### Notes and time (screen 3)

| Word | Stack | What it does |
|---|---|---|
| `HZ>PERIOD` | `( hz -- period )` | the tone period for a frequency, 2 Hz and up |
| `OCTAVE2` | `( -- addr )` | a table of 12 cells: the periods of C2 to B2 |
| `NOTE>PERIOD` | `( n -- period )` | a note number's period: n = octave x 12 + semitone (C 0 ... B 11), so 48 is C4 and 57 A4 |
| `NOTE` | `( n ch -- )` | play note n on a channel (its tone period only: set `VOLUME` and `VOICES` too) |
| `TICKS` | `( -- ms )` | the millisecond tick (ports 44h/45h), 16 bits, wrapping |
| `WAIT` | `( ms -- )` | wait that long, 0-32767 ms, by `TICKS` (the Z80 has no fixed speed) |

### Examples (screens 4 to 6)

| Word | Stack | What it does |
|---|---|---|
| `MAJOR` | `( -- addr )` | a table of 8 bytes: the major scale's steps in semitones |
| `SCALE` | `( -- )` | C4 to C5 on A, 300 ms a note |
| `CHORD` | `( n -- )` | the major chord on note n: the root on A, the third on B, the fifth on C |
| `CHORDS` | `( -- )` | C, F, G and C major |
| `SIREN` | `( -- )` | A swept down and up three times |
| `HIT` | `( period -- )` | a noise burst on C with that noise period, through a decaying envelope |
| `DRUM` | `( -- )` | four bars of low and high hits |
| `BITS` | `( -- addr )` | a table of 3 bytes: each channel's mask bit, 1 2 4 |
| `.LAYOUT` | `( n -- )` | print a stereo layout's name (1-3) |
| `PAN` | `( -- )` | A, B and C in turn in each layout, then the setting's again |
| `KOROBEINIKI` | `( -- addr )` | a tune: byte pairs of a note (0 a rest) and its length in eighths, ending 0 0 |
| `EIGHTH` | `( -- ms )` | the length of an eighth, 200 |
| `PLAY` | `( addr -- )` | play a tune table on A, each note a decay of the envelope |
| `TUNE` | `( -- )` | `KOROBEINIKI PLAY` |

Each screen's shadow (its number + 7) explains it, and `VIEW` shows a
word's source. A short session:

```
F83 AY.BLK
1 LOAD
AY? .              -1  ok
7 0 VOICES  12 0 VOLUME  12 1 VOLUME
57 0 NOTE  61 1 NOTE  1000 WAIT  QUIET
440 HZ>PERIOD .    261  ok
```
