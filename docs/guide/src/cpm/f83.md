# F83 Forth

The `F83` disk (built in, 8 MB) holds Henry Laxen and Michael Perry's F83,
FORTH-83 2.0 for CP/M-80 (public domain): `F83.COM` ready to run, the
system's source as block files (`KERNEL80.BLK`, `META80.BLK`,
`CPU8080.BLK`, `EXTEND80.BLK`, `UTILITY.BLK`), examples (`CLOCK.BLK`,
`HUFFMAN.BLK`, `BASIC.BLK`, a BASIC compiler) and its manual, `README.80`.

## Running it

Mount `F83` on B: under CP/M 2.2 or 3 and run it, with a block file to open
if you like:

```
A>B:
B>F83 CLOCK.BLK
8080 Forth 83 Model
Version 2.1.0 Modified 01Jun84
2 3 + . 5  ok
1 LIST
BYE
```

`README.80` is a WordStar file (high bits set), so `TYPE` shows it garbled;
`-READ.ME` and `F83-FIXS.TXT` are plain text.

## VIEW

`VIEW name` (and the editor's `FIX`) lists the source screen of a word. The
original F83 opens the source files on the current drive, so under CP/M 3,
where `F83` typed at `A>` is found on B: through the search path, it fails
with `Open error`. The disk's `F83.COM` is patched (`VIEWDRV.BLK`) to look
on the drive it was loaded from, which CP/M 3 records. CP/M 2.2 does not
record it, so there start F83 from its own drive (`B:`, then `F83`). After
rebuilding F83 from its source (`README.80`), `F83 VIEWDRV.BLK` and then
`1 LOAD` patch and save the new `F83.COM` the same way.

## The sound chip: AY.BLK

`AY.BLK` has words for the [AY-3-8910](../terminal/sound.md): run
`F83 AY.BLK`, then `1 LOAD`, then for example `SCALE`, `CHORDS`, `SIREN`,
`DRUM`, `PAN` (A, B and C in each stereo layout) or `TUNE`.

| Word | Stack | What it does |
|---|---|---|
| `AY!` | value register -- | write a register |
| `AY@` | register -- value | read a register |
| `AY?` | -- flag | whether the chip is there |
| `TONE` | period channel -- | set a channel's tone period |
| `VOLUME` | level channel -- | 0-15, or 16 to follow the envelope (channels 0-2: A-C) |
| `NOISE` | period -- | the noise period |
| `VOICES` | tones noises -- | the mixer: two masks (bit 0 A, 1 B, 2 C) of the channels with tone and with noise |
| `ENVELOPE` | period shape -- | start the envelope |
| `QUIET` | -- | all channels off |
| `STEREO` | n -- | the stereo layout (register 10h): 0 the setting's, 1 mono, 2 ABC, 3 ACB (decimal, as Forth reads them) |
| `HZ>PERIOD`, `NOTE>PERIOD` | n -- period | a frequency, or a note number, as a tone period |
| `NOTE` | note channel -- | play a note |
| `TICKS` | -- ms | the millisecond tick (ports 44h/45h) |
| `WAIT` | ms -- | wait that long |

Each screen's shadow (its number + 7) explains it, and `VIEW` shows a
word's source.
