# VT100 escape sequences

What the VT100 terminal type understands (`src/term/vt100.c`, on Paul
Williams' DEC parser `vtparse.c`). `ESC` is 1Bh, `CSI` is `ESC [`; `Pn`
is a number (default 1 unless stated), `Ps` a selector (default 0).
Sequences not listed are ignored.

## Control characters

| Byte | Name | Action |
|---|---|---|
| 07h | BEL | the [bell](../terminal/sound.md) |
| 08h | BS | cursor left, stopping at the left margin |
| 09h | HT | to the next tab stop (every 8 columns at reset), or the last column |
| 0Ah, 0Bh, 0Ch | LF, VT, FF | line feed: down, scrolling at the bottom margin; also to column 1 in New line mode (LNM) |
| 0Dh | CR | to column 1 |
| 0Eh | SO | use G1 |
| 0Fh | SI | use G0 |
| 18h, 1Ah | CAN, SUB | cancel a sequence in progress |
| 1Bh | ESC | starts a sequence |
| 80h-9Fh | C1 | ignored (so UTF-8 text does not trigger them) |

ENQ (no answerback) and NUL do nothing. Printable bytes 20h-7Eh are shown
in the current character set; 7Fh (DEL) is ignored.

## ESC sequences

| Sequence | Name | Action |
|---|---|---|
| `ESC D` | IND | index: down, scrolling at the bottom margin |
| `ESC E` | NEL | next line: column 1, then index |
| `ESC M` | RI | reverse index: up, scrolling down at the top margin |
| `ESC H` | HTS | set a tab stop at the cursor |
| `ESC 7` | DECSC | save the cursor: position, attributes, character sets, origin mode, wrap state |
| `ESC 8` | DECRC | restore it |
| `ESC =` | DECKPAM | keypad application mode |
| `ESC >` | DECKPNM | keypad numeric mode |
| `ESC Z` | DECID | identify: as DA |
| `ESC c` | RIS | reset to the power-on state (the SET-UP defaults) |
| `ESC # 8` | DECALN | fill the screen with `E`, margins reset |
| `ESC ( c`, `ESC ) c` | SCS | G0, G1 character set: `B` ASCII, `A` UK, `0` DEC Special Graphics |

## CSI sequences

| Sequence | Name | Action |
|---|---|---|
| `CSI Pn A` | CUU | cursor up |
| `CSI Pn B` | CUD | cursor down |
| `CSI Pn C` | CUF | cursor right |
| `CSI Pn D` | CUB | cursor left |
| `CSI Pn E` | CNL | down Pn lines, to column 1 |
| `CSI Pn F` | CPL | up Pn lines, to column 1 |
| `CSI Pn G`, `` CSI Pn ` `` | CHA, HPA | to column Pn |
| `CSI Pr ; Pc H`, `CSI Pr ; Pc f` | CUP, HVP | to row Pr, column Pc (relative to the margins in origin mode) |
| `CSI Pn d` | VPA | to row Pn |
| `CSI Ps J` | ED | erase in display: 0 to the end, 1 from the start, 2 all |
| `CSI Ps K` | EL | erase in line: 0 to the end, 1 from the start, 2 all |
| `CSI Pn L` | IL | insert lines at the cursor (within the margins) |
| `CSI Pn M` | DL | delete lines |
| `CSI Pn @` | ICH | insert blank characters |
| `CSI Pn P` | DCH | delete characters |
| `CSI Pn X` | ECH | erase characters |
| `CSI Pn S` | SU | scroll up |
| `CSI Pn T` | SD | scroll down |
| `CSI Pn b` | REP | repeat the preceding printed character Pn more times |
| `CSI Pt ; Pb r` | DECSTBM | top and bottom margins (scrolling region); cursor home |
| `CSI Ps g` | TBC | clear tabs: 0 at the cursor, 3 all |
| `CSI Pn ; ... m` | SGR | attributes and colors (below) |
| `CSI Ps h`, `CSI Ps l` | SM, RM | set, reset modes (below) |
| `CSI ? Ps h`, `CSI ? Ps l` | DECSET, DECRST | set, reset DEC private modes (below) |
| `CSI c`, `CSI 0 c` | DA | device attributes: replies `CSI ? 1 ; 2 c` (a VT100 with the Advanced Video Option) |
| `CSI 5 n` | DSR | status: replies `CSI 0 n` |
| `CSI 6 n` | DSR | cursor position report: replies `CSI Pr ; Pc R` |
| `CSI Ps x` | DECREQTPARM | terminal parameters: replies `CSI 2 ; 1 ; 1 ; 128 ; 128 ; 1 ; 0 x` (or 3 for Ps = 1): no parity, 8 bits, 38400 baud |
| `CSI ? 999 ~` | (private) | open [SET-UP](../terminal/setup.md); the following bytes are taken as keys |

Replies go to the host (in CP/M mode to the Z80's console input).

## Modes

| Mode | Set (`h`) | Reset (`l`) |
|---|---|---|
| `4` IRM | insert characters | replace |
| `20` LNM | LF also returns to column 1; Return sends CR LF | LF only goes down; Return sends CR |
| `?1` DECCKM | cursor keys send `ESC O x` | `ESC [ x` |
| `?2` DECANM | (ANSI mode) | VT52 mode; back with `ESC <` |
| `?3` DECCOLM | 132 columns (clears the screen) | 80 columns |
| `?5` DECSCNM | reverse video screen | normal |
| `?6` DECOM | origin mode: rows relative to the margins | absolute |
| `?7` DECAWM | wrap at the last column | no wrap |
| `?25` DECTCEM | cursor shown | hidden |
| `?47`, `?1047` | the alternate screen (blank) | back to the main screen, as it was |
| `?1049` | save the cursor, then the alternate screen | the main screen, then restore the cursor |
| `?67` DECBKM | Backspace sends BS | Backspace sends DEL |

Other modes (DECSCLM smooth scroll, DECARM autorepeat, ...) are ignored.
The power-on and reset values of LNM, DECBKM and the width come from
[SET-UP](../terminal/setup.md).

## SGR: attributes and colors

| Ps | Effect |
|---|---|
| 0 | all off, default colors |
| 1, 22 | bold on, off (the bold face in 80 columns; bold also brightens colors 0-7) |
| 4, 24 | underline on, off |
| 5, 25 | blink on, off |
| 7, 27 | reverse on, off |
| 30-37, 40-47 | foreground, background: the 8 ANSI colors |
| 90-97, 100-107 | foreground, background: the 8 bright colors |
| 39, 49 | default foreground, background |
| 38;5;n, 48;5;n | foreground, background: xterm 256-color palette entry n |
| 38;2;r;g;b, 48;2;r;g;b | foreground, background: 24-bit color, shown as the nearest palette entry |

How the colors look depends on SET-UP's [Colors and Palette](../terminal/colors.md).

## Character sets

`ESC ( B` / `ESC ) B` ASCII, `A` UK (# is £), `0` DEC Special Graphics
(line drawing for 60h-7Eh); SO and SI pick G1 and G0. Latin-1 characters
A0h-FFh print as themselves. See [Character set](charset.md).

## Strings

OSC, DCS, SOS, PM and APC strings are read and discarded. Any C0 control
but NUL ends one (and then acts as usual; BEL is OSC's terminator), as
does ST (`ESC \`) or 1024 bytes.
