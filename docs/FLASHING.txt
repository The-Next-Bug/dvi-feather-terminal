Flashing the DVI terminal firmware
==================================

Files: dvi_terminal-<target>.uf2 for each supported board, e.g.
dvi_terminal-feather-rp2040-dvi.uf2 for the Adafruit Feather RP2040 DVI.

1. Hold the BOOT button, press and release RESET, then release BOOT.
   (Or hold BOOT while plugging in USB.) The board appears as a USB drive
   named RPI-RP2.

2. Copy the .uf2 for your board onto that drive. The board reboots into
   the new firmware when the copy finishes.

   picotool also works: picotool load -x dvi_terminal-<target>.uf2

3. Connect a DVI/HDMI monitor. The display runs at 800x600 60 Hz.
   A demo alternates between 80 and 132 columns every 5 seconds, with the
   build id on the bottom line, until data arrives on the Feather's RX pin
   (UART0, 115200 8N1); then the terminal starts.

The BIN files are the same images as raw flash contents, for SWD programmers
(load at 0x10000000). SHA256SUMS covers the UF2 and BIN files.
